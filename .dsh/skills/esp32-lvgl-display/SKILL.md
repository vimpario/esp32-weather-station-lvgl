# Skill: esp32-lvgl-display

## Назначение
Определяет переносимый слой UI для LVGL, пригодный для разных дисплеев, включая ILI9341.

## Требования
Поддержать четыре режима отображения:
1. `numeric` — крупные числовые карточки;
2. `horizontal` — горизонтальные графики/полосы;
3. `bars` — столбчатая диаграмма;
4. `gauges` — круговые шкалы.

## Правила
- UI строить на LVGL, а не на HTML/CSS.
- Логика данных не должна знать конкретный контроллер дисплея.
- Драйвер панели и touch/input должны быть вынесены в board/display adapter.
- Размеры и отступы задавать через адаптивные константы/лейаут, а не через случайные абсолютные координаты.
- Не использовать шрифты/иконки, которые невозможно встроить во flash локально.
- Для ILI9341 предусмотреть отдельную инициализацию SPI и rotation, не меняя модель UI.
- Переключение вкладок/режимов должно менять только presentation state.

## Цветовая семантика
Типы данных имеют стабильную базовую цветовую роль:
- температура: оттенок от холодного синего к горячему красному;
- влажность: отдельная водная/бирюзовая гамма;
- давление: отдельная нейтральная/фиолетовая гамма.

Состояние данных имеет дополнительный статус:
- `ok` — нормальная насыщенность;
- `stale` — приглушённый вид;
- `error` — заметный предупреждающий контур/индикатор.

## Иконки
Каждая шкала/карточка обязана иметь локальную иконку, визуально объясняющую измерение: термометр, капля, барометр.

## Приёмка
Каждый из четырёх режимов должен работать на базовом размере экрана и не зависеть от HTML UI. Для ILI9341 смена дисплея не должна требовать переписывать бизнес-логику сенсоров.
