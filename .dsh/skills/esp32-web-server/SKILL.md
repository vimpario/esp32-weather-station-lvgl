# Skill: esp32-web-server

## Назначение
Реализует локальный HTTP API и доставку живых данных измерений на браузер.

## Архитектура
ESP32 выступает одновременно как:
1. HTTP server для `web/index.html` и статических ресурсов;
2. API provider для текущих показаний;
3. источник push-обновлений, предпочтительно через Server-Sent Events (SSE) или WebSocket.

## Рекомендуемый контракт
`GET /api/weather`
```json
{
  "temperature": 23.4,
  "humidity": 48,
  "pressure": 1012.6,
  "updatedAt": 1710000000000,
  "valid": true
}
```

Допускается `GET /api/stream` для SSE. Частота UI обновления не должна быть жёстко связана с частотой физического опроса датчиков.

## Правила
- Никаких внешних JS/CSS CDN.
- API возвращает JSON с единицами, понятными клиенту.
- Ошибки сенсоров должны быть явно представлены.
- Установить `Cache-Control: no-store` для живых данных.
- HTML, JS и стили должны оставаться пригодными для автономной работы на ESP32.
- Избегать больших временных буферов и динамического выделения памяти на каждый запрос.
- Не блокировать loop долгими HTTP операциями.

## Приёмка
- Главная страница открывается по IP ESP32.
- API отдаёт валидный JSON.
- Данные меняются без ручного refresh.
- При потере сенсора браузер показывает stale/error state, но не падает.
