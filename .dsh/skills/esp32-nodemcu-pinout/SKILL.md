# Skill: esp32-nodemcu-pinout

## Назначение
Отвечает за безопасное и однозначное назначение GPIO для ESP32 NodeMCU-32S в проекте метеостанции.

## Зафиксированная схема
| Датчик | Вывод | ESP32 |
|---|---|---|
| BMP280 | VCC | 3.3V |
| BMP280 | GND | GND |
| BMP280 | SCL | GPIO22 |
| BMP280 | SDA | GPIO21 |
| BMP280 | CSB | 3.3V |
| BMP280 | SDO / SDD | GND |
| DHT11 | + | 3.3V |
| DHT11 | OUT | GPIO4 |
| DHT11 | – | GND |

## Правила
- Не менять GPIO21/22 без явного требования пользователя: это I²C шина проекта.
- Не использовать GPIO4 для других периферийных функций.
- Учитывать boot-strapping и потенциально конфликтующие GPIO ESP32 при добавлении нового железа.
- Проверять, что дисплей ILI9341 не занимает GPIO21/22/4 в выбранной конфигурации.
- Все pin assignments держать в одном месте исходников через именованные константы.
- Не подключать BMP280 к 5V, если конкретный модуль не имеет подтверждённого преобразователя уровней/регулятора.

## Приёмочные проверки
1. I²C сканер видит BMP280 на ожидаемом адресе.
2. DHT11 стабильно отвечает на GPIO4.
3. Нет двойного назначения GPIO.
4. Схема подключения и код используют одинаковые номера GPIO.

## Формат результата для агента
Сначала вывести таблицу pin mapping, затем перечислить занятые GPIO и только после этого генерировать код.
