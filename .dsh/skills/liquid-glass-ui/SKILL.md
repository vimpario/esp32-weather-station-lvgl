# Skill: liquid-glass-ui

## Назначение
Формирует визуальный язык веб-интерфейса метеостанции в стиле Liquid Glass, но с учётом ограничений ESP32.

## Визуальные принципы
- Полупрозрачные карточки.
- Мягкое размытие/имитация blur только там, где это не вызывает чрезмерной нагрузки; иметь fallback без blur.
- Тонкая светлая граница.
- Большие скругления.
- Мягкая тень и высокий контраст текста.
- Спокойный фон с глубиной, но без тяжёлых изображений.

## Навигация
Четыре переключателя, каждый отвечает за свой режим:
- Numbers
- Horizontal
- Bars
- Gauges

Активная вкладка визуально выделена и синхронизирована с выбранным режимом.

## Семантические состояния
Температура:
- холодно → синий;
- комфорт → зелёно/нейтральный;
- жарко → оранжево-красный.

Влажность:
- низкая → жёлто-золотистый;
- комфорт → бирюзовый;
- высокая → сине-фиолетовый.

Давление:
- низкое → фиолетово/синее;
- нормальное → зелёно;
- высокое → янтарное.

Пороговые значения должны быть вынесены в конфигурацию, а не разбросаны по UI.

## Производительность
- Не подключать внешние библиотеки шрифтов, иконок, CSS или JS.
- Снижать количество переотрисовок.
- Не создавать DOM-элементы заново при каждом обновлении данных.
- Для старых/малых экранов иметь fallback без backdrop-filter.
