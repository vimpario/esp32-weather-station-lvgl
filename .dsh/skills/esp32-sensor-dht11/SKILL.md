# Skill: esp32-sensor-dht11

## Назначение
Инкапсулирует работу с DHT11 для измерения относительной влажности и температуры.

## Hardware contract
- `+`: 3.3V
- `OUT`: GPIO4
- `–`: GND

## Правила кода
- Не читать DHT11 слишком часто; использовать безопасный интервал опроса, чтобы избежать некорректных значений.
- Отделить физический опрос от Web/LVGL loop.
- Возвращать одновременно влажность и температуру, с признаком валидности.
- Не замалчивать checksum/read errors.
- Не позволять блокирующему чтению сенсора останавливать Wi-Fi/Web/LVGL обработку на заметное время.
- Температуру DHT11 использовать как отдельный источник; не смешивать её автоматически с BMP280.

## Данные наружу
```text
dht11.temperature_c
dht11.humidity_pct
dht11.valid
dht11.updated_at_ms
```

## Приёмка
- Влажность находится в диапазоне 0…100 %.
- Ошибки чтения не ломают основной цикл.
- Данные получают корректное время последнего обновления.
