# Skill: esp32-sensor-bmp280

## Назначение
Инкапсулирует работу с BMP280 по I²C для получения температуры и атмосферного давления.

## Hardware contract
- VCC: 3.3V
- GND: GND
- SDA: GPIO21
- SCL: GPIO22
- CSB: 3.3V — выбор I²C режима
- SDO/SDD: GND — адрес I²C `0x76` для типичного BMP280

## Правила кода
- Использовать I²C, а не SPI.
- Перед использованием сенсора проверять успешность `begin`/инициализации.
- Явно задавать SDA/SCL в коде, не полагаться на неявные pins.
- Хранить давление в Па внутри слоя сенсора; преобразовывать в hPa для UI/API.
- Температуру нормализовать к °C.
- При ошибке чтения не подменять данные нулями: возвращать состояние `invalid/stale`.
- Фильтрацию делать в слое данных, а не внутри драйвера, если это не требуется библиотекой.

## Данные наружу
Рекомендуемая модель:
```text
bmp280.temperature_c
bmp280.pressure_hpa
bmp280.valid
bmp280.updated_at_ms
```

## Приёмка
- Инициализация проходит без reset loop.
- Значения температуры и давления физически правдоподобны.
- Ошибка отсутствующего сенсора диагностируется через Serial.
- UI продолжает работать даже при временно недоступном сенсоре.
