# Skill: esp32-wifi

## Назначение
Отвечает за подключение ESP32 к локальной Wi‑Fi сети и получение IP для метеостанции.

## Требования проекта
- SSID: `Beeline_2G_F121F9`
- Пароль: хранить только в локальном `include/secrets.h`; **не коммитить секрет в репозиторий**.
- Статический IPv4 ESP32: `192.168.1.111`
- Подсеть: `255.255.255.0`
- Шлюз: `192.168.1.1`
- DNS1: `192.168.1.1`
- DNS2: `1.1.1.1`

## Критически важно
ESP32 должна использовать **статический** IPv4 `192.168.1.111`. Не заменять его на DHCP-адрес. Перед запуском убедиться, что `192.168.1.111` свободен в локальной сети и не конфликтует с DHCP pool роутера.

## Правила
- Секреты не хранить в `README.md`, `SKILL.md`, `main.cpp`, `index.html` или `platformio.ini`.
- Для локальной разработки использовать untracked `include/secrets.h` или иной локальный механизм, исключённый из Git.
- После подключения печатать в Serial: статус Wi‑Fi, SSID, IP, RSSI.
- Не делать бесконечный blocking wait без таймаута.
- При потере Wi‑Fi автоматически выполнять повторное подключение.
- Web UI не должен зависеть от внешнего CDN: всё должно работать в локальной сети без доступа в Интернет.

## Приёмка
- ESP32 подключается к сети `Beeline_2G_F121F9`.
- В Serial появляется именно `192.168.1.111`.
- Gateway определяется как `192.168.1.1`.
- После временного отключения AP выполняется recovery с сохранением статического адреса.
- Веб-сервер снова доступен без перезагрузки питания.
